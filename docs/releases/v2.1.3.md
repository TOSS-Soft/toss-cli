# TOSS CLI v2.1.3

## Correction

The embedded Core implementation has been removed from TOSS CLI. The product
package now exposes only the `toss` executable and retains its shared product
contracts, output surfaces, pipeline contracts, and templates.

## Core extraction

Core is independently owned by `@toss-soft/core@0.1.0`. The accepted
`TOSS-Soft/toss-core` main commit is
`126986a97a2123db9f20d4bf8ca165b8ded2bde5`. The reviewed raw
`npm pack --dry-run --json --ignore-scripts` SHA-256 digest is
`d51a1123662a0b2c38e8aa6b69fcd5eb77e3160f97ab55b38400097df4ac69d3`.

## Compatibility

The `toss` command behavior remains in this package. Core organizational
lifecycle commands and schemas are no longer bundled with TOSS CLI, and TOSS
CLI must not depend on either `@toss-soft/core` or the superseded
`@toss-software/core` identity.

## Verification

The product Core-removal boundary, schema catalog, manifest, and test-boundary
integrity checks verify the reduced ownership surface. The lockfile refresh
also updates the vulnerable transitive `fast-uri` entry to a fixed release.
