# Agent Registry

## Status Vocabulary

APPROVED, ACTIVE, DISABLED, DEPRECATED, and UNKNOWN identify registry or assignment state.

## Active Specialist

| Specialist | Status | Capability | Environment | Allowed Actions | Prohibited Actions |
| --- | --- | --- | --- | --- | --- |
| NONE | NONE | NONE | NONE | NONE | NONE |

## Capability

Each specialist must have an approved capability matching the assigned Task.

## Environment

Each assignment names only the environments required for the Task.

## Allowed Actions

Allowed actions are explicit and limited by the Task Contract.

## Prohibited Actions

Specialists may not expand scope, assign binding work, alter authority, disclose secrets, or infer production authority.

## Assignment and Task Contract Requirement

An ACTIVE specialist requires a PM assignment and frozen Task Contract before material execution.
